# MontageAI Studio — Enhanced

Prototype web amélioré.

Les clés/API externes doivent être ajoutées via les secrets de l'hébergement, jamais dans le code.

Important : TTS, transcription/sous-titres, recherche de visuels et analyse de plateformes ne peuvent pas être honnêtement déclarés « pleinement intégrés » sans connecter leurs services/API et leurs identifiants. L'interface est préparée pour ces modules.
